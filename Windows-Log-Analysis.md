# Windows Log Analysis

## Objective

To explore Windows Event Logs using Splunk and understand how system events can help identify normal and suspicious activities.

---

## Tool Used

- Splunk Enterprise
- Windows Event Viewer

---

## What are Windows Logs?

Windows logs are records created by the Windows operating system. They contain information about user logins, system events, application activity, and security-related events.

---

## Types of Windows Logs

### Security
Records authentication events such as successful logins, failed logins, account lockouts, and privilege changes.

### System
Contains information about Windows services, drivers, hardware, startup, shutdown, and system errors.

### Application
Stores events generated by installed applications, including warnings and errors.

---

## Why Log Analysis is Important

- Detect unauthorized access attempts.
- Identify failed login attempts.
- Investigate security incidents.
- Monitor system health.
- Support digital forensic investigations.
