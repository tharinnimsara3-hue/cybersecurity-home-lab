# Security Monitoring Review

## SIEM

Security Information and Event Management systems collect and analyze logs from multiple sources.

## Incident Response

The six phases are:

1. Preparation
2. Identification
3. Containment
4. Eradication
5. Recovery
6. Lessons Learned

## Threat Hunting

Threat hunting is the proactive search for suspicious activities that may not generate alerts.

## MITRE ATT&CK

MITRE ATT&CK maps real-world attacker tactics and techniques to improve threat detection and response.

## Security Monitoring

SOC analysts monitor:

- Failed logins
- Suspicious network activity
- Malware alerts
- Authentication logs
- Firewall events

## What I Learned

Effective security monitoring combines log analysis, incident response, and proactive threat hunting.
