# Threat Hunting Basics

## What is Threat Hunting?

Threat hunting is the proactive process of searching for suspicious activities that may not have generated security alerts.

## Why is Threat Hunting Important?

- Identifies hidden threats.
- Detects advanced attacks.
- Improves organizational security.
- Reduces incident response times.

## Examples of Threat Hunting Activities

- Searching for multiple failed logins.
- Looking for unusual user behavior.
- Detecting abnormal network connections.
- Monitoring suspicious processes.
- Identifying unauthorized software installations.

## Threat Hunting Process

1. Create a hypothesis.
2. Collect security logs.
3. Analyze the data.
4. Investigate suspicious findings.
5. Document the results.

## Example

Hypothesis:

"A user account generated unusually high numbers of failed logins during non-business hours."

Investigation:

- Review authentication logs.
- Identify affected systems.
- Determine whether unauthorized access occurred.

## What I Learned

Threat hunting allows security analysts to identify suspicious activities before they become serious security incidents.
