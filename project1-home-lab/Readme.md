# Home Lab + Network Hardening Project

## Objective

Build a virtual cybersecurity lab using Kali Linux, Ubuntu Server, and pfSense firewall to practice networking, Linux administration, and system hardening.

---

## Lab Components

- Kali Linux
- Ubuntu Server
- pfSense Firewall
- VirtualBox

---

## Skills Practiced

- Nmap scanning
- Wireshark packet analysis
- SSH configuration
- Firewall rules
- Linux permissions
- Authentication log monitoring
- Basic Linux hardening

---

## Tools Used

| Tool | Purpose |
|------|---------|
| Nmap | Network scanning |
| Wireshark | Packet capture |
| pfSense | Firewall/router |
| SSH | Secure remote access |
| UFW | Linux firewall |

---

## Activities Performed

- Installed pfSense
- Configured Ubuntu Server
- Configured SSH
- Performed Nmap scans
- Captured packets using Wireshark
- Enabled UFW firewall
- Monitored auth logs
- Practiced Linux hardening
