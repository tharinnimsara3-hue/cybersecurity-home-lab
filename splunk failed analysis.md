# Failed Login Analysis

## Objective

Generate failed Windows login attempts and analyze them using Splunk.

## Event ID

4625

## Description

Windows records Event ID 4625 whenever a user enters an incorrect password.

## Why It Is Important

SOC analysts monitor repeated failed logins because they may indicate:

- Brute-force attacks
- Password guessing
- Unauthorized access attempts
