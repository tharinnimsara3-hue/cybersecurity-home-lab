# Project 3 - Mini SOC / Log Monitoring

## Objective

To build a basic Security Operations Center (SOC) lab and understand security monitoring concepts.

## Tools Used

- Splunk Enterprise
- Windows Event Viewer
- Kali Linux
- Ubuntu Linux
- VirtualBox

## Activities Performed

- Studied SIEM basics.
- Learned Windows Event IDs.
- Reviewed Linux authentication logs.
- Learned incident response.
- Studied MITRE ATT&CK.
- Practiced threat hunting.
- Created incident reports.

## Skills Developed

- Log Analysis
- Security Monitoring
- Incident Response
- Threat Hunting
- Security Documentation

## Challenges Faced

- Splunk installation issues.
- Virtual machine performance limitations.
- Network configuration troubleshooting.

## Conclusion

This project improved my understanding of SOC operations and provided practical experience with cybersecurity monitoring concepts.
