# Security Monitoring Basics

## What is Security Monitoring?

Security monitoring is the continuous process of observing systems, networks, and applications to identify suspicious or malicious activities.

## Why is Security Monitoring Important?

- Detects security incidents quickly.
- Helps prevent data breaches.
- Supports incident response activities.
- Improves organizational security.

## What Do SOC Analysts Monitor?

- Failed login attempts.
- Successful logins from unusual locations.
- Suspicious network activity.
- Malware alerts.
- Unauthorized privilege changes.
- Firewall and SIEM alerts.

## Common Security Monitoring Tools

- Splunk
- Wazuh
- Microsoft Sentinel
- Elastic (ELK Stack)
- Windows Event Viewer

## Security Monitoring Process

1. Collect logs.
2. Monitor alerts.
3. Investigate suspicious activities.
4. Perform incident triage.
5. Respond to security incidents.
6. Document findings.

## What I Learned

Security monitoring is one of the most important responsibilities of a SOC Analyst because it enables organizations to detect threats quickly and respond appropriately.
