Social Engineering Attacks
 Phishing

Fake emails/messages used to steal passwords or information.

Example:
Fake bank email asking login details.

 Smishing

Phishing through SMS/text messages.

Example:
"Your package delayed. Click link."

 Vishing

Phishing using phone calls.

Example:
Scammer pretending to be bank staff.

 Whaling

Phishing targeting important people (CEO, managers).

Example:
Fake email to company director.

 Tailgating

Unauthorized person enters secure area by following someone.

Example:
Walking behind employee through access door.

 Shoulder Surfing

Watching someone type password or PIN.

Example:
Seeing ATM PIN.

 Password Attacks
 Brute Force Attack

Trying many password combinations until correct one found.

 Dictionary Attack

Trying passwords from common word lists.

Example:

password123
admin123
welcome1
 Password Spraying

Trying one common password on many accounts.

Example:

Spring2025!

against many users.

 Credential Stuffing

Using leaked username/password combinations from breaches.

 Vulnerabilities
 Weak Passwords

Simple passwords easy to guess.

 Unpatched Software

Old software missing security updates.

 Misconfigured Firewall

Firewall rules incorrectly allow dangerous traffic.

 Attack Types
 DoS (Denial of Service)

Attack overloads system causing service interruption.

 DDoS (Distributed Denial of Service)

Many computers attack target simultaneously.

 MITM (Man-in-the-Middle)

Attacker secretly intercepts communication.

Example:

User → Attacker → Website
 Replay Attack

Attacker captures data then sends it again later.

 Injection Attack

Malicious code inserted into application.

Example:

SQL Injection.

 Malware Types
 Virus

Malware attaching to files/programs and spreading.

 Worm

Self-spreading malware without user action.

 Trojan

Malware pretending to be legitimate software.

 Ransomware

Encrypts files and demands money.

 Spyware

Secretly monitors user activity.

 Extra Important Terms
 CIA Triad

Confidentiality

Protect information from unauthorized access.

Integrity

Ensure information is not changed improperly.

Availability

Systems remain accessible when needed.
