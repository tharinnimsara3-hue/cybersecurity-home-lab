# Incident Response Basics

## What is Incident Response?

Incident response is the process of identifying, investigating, containing, and recovering from security incidents.

## Why is Incident Response Important?

- Minimizes damage.
- Reduces recovery time.
- Protects sensitive information.
- Improves an organization's security posture.

## Incident Response Lifecycle

1. Preparation
2. Identification
3. Containment
4. Eradication
5. Recovery
6. Lessons Learned

## Example Incident

- Multiple failed login attempts detected.
- SOC analyst investigates the alert.
- The affected account is temporarily locked.
- Password is reset.
- Logs are reviewed to determine the source.
- The incident is documented.

## What I Learned

Incident response provides a structured approach for handling cybersecurity incidents effectively.
