# SOC Investigation Basics

## What is a SOC Investigation?

A SOC investigation is the process of examining security events and alerts to determine whether malicious activity has occurred.

## Investigation Process

1. Receive the alert.
2. Verify whether the alert is legitimate.
3. Collect logs and evidence.
4. Identify affected systems and users.
5. Determine the severity of the incident.
6. Recommend containment actions.
7. Document the findings.

## Questions SOC Analysts Ask

- What happened?
- When did it happen?
- Who was affected?
- Which systems were involved?
- Is the activity malicious?
- What should be done next?

## Evidence Sources

- Windows Event Logs
- Linux Authentication Logs
- SIEM Alerts
- Firewall Logs
- Network Traffic Logs

## What I Learned

SOC investigations rely on log analysis, evidence collection, and proper documentation to determine whether suspicious activity is a real security incident.
