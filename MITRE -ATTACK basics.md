# MITRE ATT&CK Basics

## What is MITRE ATT&CK?

MITRE ATT&CK is a knowledge base that documents the tactics and techniques used by cyber attackers based on real-world observations.

## Why is it Important?

- Helps security teams understand attacker behavior.
- Improves threat detection.
- Supports incident response.
- Maps attacks to known techniques.

## Common Tactics

- Initial Access
- Execution
- Persistence
- Privilege Escalation
- Defense Evasion
- Credential Access
- Discovery
- Lateral Movement
- Collection
- Command and Control
- Exfiltration
- Impact

## Example Technique

Brute Force (T1110)

Description:
An attacker repeatedly attempts different passwords until the correct one is found.

Detection:
- Monitor repeated failed login attempts.
- Create SIEM alerts.
- Review authentication logs.

Mitigation:
- Strong passwords
- Multi-factor authentication
- Account lockout policy

## What I Learned

The MITRE ATT&CK framework helps SOC analysts understand, detect, and respond to cyber attacks using standardized tactics and techniques.
