# OWASP ZAP Basics

## Purpose

OWASP ZAP is a web application security testing tool.

## Key Features

- Proxy
- Traffic inspection
- Spidering
- Passive scanning
- Vulnerability identification

## Components

### Sites Tree
Lists discovered websites.

### Request Panel
Displays requests sent by browser.

### Response Panel
Displays server responses.

### Alerts
Displays security findings.

## Learning Outcome

Learned how web traffic can be inspected using a proxy.
