# Executive Summary
This report documents the initial stages of a vulnerability assessment lab. The purpose of this exercise is to understand basic security testing workflows, including authentication analysis, session handling, and tool usage in a controlled environment. No real-world systems were targeted.

---

# Scope
The scope of this assessment is limited to:
- A local or intentionally vulnerable web application (lab environment)
- Authentication mechanisms (login functionality)
- Session management behavior (cookies and session tracking)
- Network traffic observation during login attempts

Out of scope:
- External websites
- Real production systems
- Any form of unauthorized testing

---

# Methodology
The following methodology was used during the assessment:

1. Accessed the target web application in a controlled lab environment.
2. Created a test user account for authentication testing.
3. Monitored HTTP traffic using browser Developer Tools.
4. Captured login requests and analyzed request/response structure.
5. Observed session cookies after successful authentication.
6. Reviewed session behavior during login and logout actions.

This approach follows a basic black-box testing method, where no internal source code is accessed.

---

# Tools Used
The following tools were used during the assessment:

- Mozilla Firefox / Google Chrome (Web Browser)
- Browser Developer Tools (Network tab, Application/Storage tab)
- Optional: OWASP ZAP / Burp Suite Community Edition (if used in lab)
