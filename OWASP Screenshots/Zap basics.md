# OWASP ZAP Basics

## Objective
Understand how OWASP ZAP captures and analyzes web traffic.

## Activities
- Opened OWASP ZAP
- Explored the interface
- Visited a legal practice website
- Observed captured HTTP requests

## Key Features Learned
- Spider
- Passive Scan
- Active Scan
- Alerts
- History

## What I Learned
OWASP ZAP acts as a web security testing tool that can inspect requests and responses between a browser and a web application.
